# 🌐 Personal Portfolio Website

## 📌 Overview
This is a modern and responsive personal portfolio website showcasing my skills, projects, education, and contact information. The portfolio highlights my software development experience, technical skills, and project work in an attractive and user-friendly interface.

---

## 🚀 Features

- Responsive design for desktop, tablet, and mobile devices
- Professional home and about sections
- Skills showcase with categorized technologies
- Project gallery with direct GitHub repository links
- Contact section with social media links
- Smooth scrolling and modern UI design
- Profile image integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages (Deployment)
